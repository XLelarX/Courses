# Базовый синтаксис Java

## Строки и массивы

Это объекты класса String, в некоторых случаях обрабатываются отлично от всех остальных объектов. Строковые литералы записываются в двойных кавычках.

Объявление массивов:
```
int[]array1 = new int[10];
int[]array2 = {1, 2, 3};
[1, 2, 3] int[][]array3 = new int[5][5];
int[][]array4 = {{1, 2}, {3, 4}, {5, 6}};
```

## Объявление и инициализация переменной

Общая схема: <тип данных> <имя переменной> [ = <значение>]
```
byte b = 64;
short s = 1024;
char c = 'C';
int i = 2048;
long l = 419304;
boolean bool = true;
float = 0.5;
double d = 1.2;
String str = "Gosling"
```

## Условный оператор if – else

Состоит из логического выражения, после которого следует один или более операторов. Может сопровождаться дополнительным оператором else, который выполняется при ложном логическом выражении.

```
if (булевое выражение) {
// Выполняется, если истинно
} else {
// Выполняется, если ложно
}

## Условный оператор switch
Проверяет переменную на равенство в отношении списка значений.
```
switch (выражение) {
	case значение:
		// Операторы
		break; // Необязательно
	case значение2:
		// Операторы
		break; // Необязательно
		
...
	default: // Необязательно
		// Операторы
}

## Тернарный операторр

Тернарный оператор - сокращенная форма if – else:

<условие> ? <значение, если true> : <значение, если false>

Пример:

```String result = age >= 18 ? "Все хорошо" : "Фильм не подходит для вашего возраста";```

## Циклы for и forEach

* for - Обладает структурой управления повторений, что позволяет эффективно написать цикл, который должен выполниться определенное количество раз.
```
for (<инициализация>; <лог выражение>; <обновление>) {
...
}
```

* forEach - это разновидность цикла for, которая используется, когда нужно обработать все элементы массива или коллекции.
```
for (<тип> <имя переменной> : <коллекция>)
{
...
}
```

## Циклы while и do-while

* while - многократно выполняет цель оператора до тех пор, пока данное условие верно.
```
while (<лог выражение>) {
...
}
```

* do-while - похож на цикл while, отличие, что цикл do-while гарантированно выполнится, по крайней мере один раз.
```
do {
...
} while (<лог выражение>);
```
## Комментарии

Язык Java поддерживает однострочные и многострочные комментарии, они очень похожи на используемые в С/С++. Все символы недоступны внутри любых комментариев и игнорируются компилятором.

```
/**
* Многострочный комментарий
*/

// Однострочный комментарий
```
